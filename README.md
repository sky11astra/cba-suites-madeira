# CBA Suites Madeira — сайт апартаментів у Фуншалі

Статичний сайт без фреймворків, 7 мов: `/` — English, `/uk/` — українська, `/pt/` — português, `/de/` — Deutsch, `/fr/` — français, `/pl/` — polski, `/ru/` — русский.
Зроблений на основі шаблону `madeira-tour` (та сама система збірки, мовні пакети, SEO/GEO-файли).

**Запуск:** двічі клацнути `ЗАПУСТИТИ_САЙТ.bat` (відкриє http://localhost:5250). Готовий сайт лежить у `dist/` — саме цю папку викладають на хостинг.

## Що на сторінці
- **Hero «крізь мансардне вікно»**: під час скролу камера «пролітає» крізь мансардне вікно лофту і відкриває панораму Фуншала з балкона Superior Suite. Праворуч угорі — живий час у Фуншалі, схід/захід сонця (рахується в браузері, без API) і середня температура повітря й моря за поточний місяць.
- **8 типів номерів** із даних Booking.com: площа, ліжка, вигляд, балкон/тераса, зручності й фото саме цього типу. Клік відкриває вікно номера з галереєю.
- **Басейн на WebGL**: вода «оживає» — відблиски і хвилі від курсора чи пальця (хвилі спотворюють лише воду, не плитку).
- **Карта «усе пішки»**: справжня мапа вулиць центру Фуншала з OpenStreetMap, кола 5–25 хвилин і 20 реальних пішохідних маршрутів від дверей готелю (OSRM). Маршрути малюються анімовано, карта сама «показує» найважливіші місця.
- **Тури островом**: 18 напрямків з часом у дорозі від готелю, фільтри, карта Мадейри з лініями маршрутів, що підсвічуються під час скролу.
- **Коли їхати**: графік температури повітря й моря по місяцях + події місяця (карнавал, свято квітів, феєрверки тощо).
- **Відгуки**: оцінки Booking.com (8,4 / 945) і Google (4,3 / 117), підоцінки, теми, які гості згадують найчастіше.
- **Галерея** з фільтрами й лайтбоксом, **FAQ**, **бронювання**: форма збирає дати й гостей і відправляє готове повідомлення у WhatsApp/email або відкриває Booking.com з уже вибраними датами.

## Демо онлайн
https://sky11astra.github.io/cba-suites-madeira/ — GitHub Pages, репозиторій `sky11astra/cba-suites-madeira`. Кожен push у `main` автоматично викладає папку `dist/` (`.github/workflows/pages.yml`).
Зараз увімкнено `demo: true`: сторінки мають `noindex`, тож Google їх не показує, поки власник не погодить сайт.

## Перед справжнім запуском — перевірити `src/config.mjs`
- `siteUrl` — справжній домен замість адреси GitHub Pages; `demo: false` — відкрити сайт для пошуковиків. Обидва потрібні для canonical, hreflang, sitemap, соцмереж.
- `contacts` — телефон/WhatsApp і email взято з **madeirabymlv.com** (сайт, указаний у профілі CBA Suites на Google Maps). Підтвердити з власником.
- `price` у `src/data/suites.mjs` — «від €75» (студія) і «від €90» (люкс з видом на місто) з того ж сайту. Решта типів — «ціна за запитом».
- Фото номерів і будинку — з Booking.com (належать готелю) і 2 фото фасаду з шаблону. Використання на сайті готелю варто погодити з власником.

Після змін: `npm run build` (або `node build.mjs`). Якщо змінили фото — спершу `npm run images`, якщо дані карти — `npm run map`.

## Структура
- `src/config.mjs` — бренд, домен, контакти, адреса, координати, ліцензія AL, посилання, оцінки, мови.
- `src/i18n/<мова>.mjs` — усі тексти однією мовою (однакова структура). Щоб додати мову: скопіювати `en.mjs`, перекласти, додати в `langs`.
- `src/data/suites.mjs` — типи номерів (площа, гості, вигляд, зручності, фото); `gallery.mjs` — галерея; `climate.mjs` — середні температури.
- `src/data/places.json` — місця для карти пішки й турів (координати OSM, час авто).
- `src/template.mjs`, `src/styles.css`, `src/app.js`, `build.mjs` — HTML, дизайн, логіка, збірка.
- `tools/images.py` — фото → AVIF + WebP у кількох ширинах, OG-картинка, іконки. `tools/map.py` — карта Фуншала з даних OSM.
- `assets/booking/` — оригінали фото з Booking (3000 px), `assets/tours/` — фото місць з Wikimedia Commons (автори й ліцензії в `credits.json` і у футері), `assets/osm/` — дані OpenStreetMap і маршрути.

## SEO / GEO
- Окрема сторінка на кожну мову з `hreflang`, canonical, Open Graph, geo-мета (Funchal, PT-30, координати).
- Schema.org JSON-LD: `Hotel` (адреса, координати, карта, check-in/out, зручності, 8 типів номерів з площею й місткістю, ліцензія AL), два `ItemList` (місця поруч з відстанями пішки, тури з координатами), `FAQPage`.
  Оцінки з Booking/Google у schema свідомо не додано: Google не дозволяє розмічати чужі відгуки на власному сайті.
- `robots.txt` відкритий для Google і AI-пошуку (ChatGPT, Claude, Perplexity), `sitemap.xml` з мовами й фото, `llms.txt` — стислий опис для AI-асистентів.
- Швидкість: увесь текст у HTML одразу, CSS і JS вбудовані (≈45 КБ після стиснення), головне фото ≈60 КБ (AVIF) з preload, решта фото ліниво.
- Після публікації: вказати адресу сайту в Google Business Profile і на Booking.com, щоб назва, адреса й телефон збігалися всюди.
